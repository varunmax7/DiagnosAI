## 📌 Overview
An AI/ML-powered health monitoring system designed for hostel/residential campuses that:
- Provides **early detection** of health issues through symptom analysis
- Streamlines **medical record management** for students
- Offers **personalized health insights** with predictive capabilities
- Ensures **data privacy** while enabling institutional oversight

## 🛠️ Tech Stack
- **Frontend**: Flask, HTML5, CSS3, JavaScript
- **Backend**: Python, SQLite
- **AI/ML**: Symptom prediction models (Rule-based + ML)
- **Security**: Password hashing, Session management

## ✨ Key Features
| Feature | Benefit |
|---------|---------|
| Symptom Checker | Instant AI analysis of reported symptoms |
| Health Dashboard | Track symptom history and patterns |
| Alert System | Flags potential outbreaks in hostel |
| Admin Portal | Institutional health monitoring |
| Privacy Controls | Student-controlled data sharing |
